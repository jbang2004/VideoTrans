# Postable 克隆

这是一个模仿 Postable.app 网站的前端动画效果实现。主要功能是展示如何实现从推文链接生成社交媒体帖子的界面动画。

## 功能特点

- 模拟浏览器框架UI设计
- 实现 Postable 按钮的点击动画效果
  - 彩色横幅从底部向上扩展
  - 黑色按钮从中间向两侧拉伸
- 响应式设计
- 粘贴功能支持

## 如何使用

### 方法一：使用开发服务器（推荐）

1. 确保已安装 [Node.js](https://nodejs.org/)
2. 在项目根目录下运行以下命令启动开发服务器：
   ```
   npm run dev
   ```
3. 浏览器会自动打开 http://localhost:3000
4. 点击中间的 "Postable" 按钮查看动画效果
5. 点击页面其他区域可以返回初始状态

### 方法二：直接打开文件

1. 直接在浏览器中打开 `index.html` 文件
2. 点击中间的 "Postable" 按钮查看动画效果
3. 点击页面其他区域可以返回初始状态

## 技术说明

- 使用纯 HTML, CSS 和 JavaScript 实现
- 使用 Vite 作为开发服务器
- 无需任何外部框架或库
- 仅使用 Font Awesome CDN 引入图标

## 浏览器兼容性

- Chrome (推荐)
- Firefox
- Safari
- Edge

## 注意事项

- 剪贴板功能需要在安全上下文 (HTTPS 或 localhost) 中运行才能正常工作
- 在某些浏览器中可能需要用户授予剪贴板访问权限
